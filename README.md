# kali-yantra

Standalone generator that renders a Kali yantra image with Pillow (PIL),
using supersampling for clean edges.

- Generate the image: double-click **Draw Yantra.command** (writes `kali_yantra.jpg`)
- Or run directly: `python3 kali_yantra.py`

Requires: Python 3 with Pillow (`pip3 install pillow`).
